# Cursivis DataOps 0.1.0 Beta 1

Cursivis DataOps is a context-native Windows AI agent for data engineers and analysts. Select SQL or a data error, invoke Cursivis, and the judge-facing DataOps flow resolves the referenced asset through the official DataHub MCP Server before Gemini reasons over verified organizational context.

## Hackathon flow

- **DataHub OSS / Core** hosts the deterministic demo catalog and remains the source of truth for schema, ownership, descriptions, and lineage.
- **DataHub MCP Server** participates in the runtime read path using the official MCP tools for catalog/entity/schema/lineage context.
- **Gemini** is the primary reasoning provider for the DataOps result.
- **Cursivis** renders the grounded answer and supports safe Copy / Insert / Replace actions.
- **Save to DataHub** is an explicit confirmation-gated MCP write-back. Cursivis verifies the saved knowledge with a follow-up MCP read before reporting success.

The canonical demo intentionally selects broken SQL against `analytics.customers`. DataHub exposes the governed fields `customer_id`, `lifetime_value_usd`, `customer_tier`, and `updated_at`, plus ownership and downstream lineage, so Gemini can correct the query without inventing organizational metadata.

## Install and run

1. Download `Cursivis-Setup-x64.exe` (or the versioned installer) from this release and complete installation.
2. Install/start Docker Desktop and follow the repository's **Quick setup (Windows)** instructions to bootstrap and seed the local DataHub OSS demo catalog.
3. Configure your own Gemini Developer API key in **AI & DataHub** settings or `.env`; no API key is bundled.
4. Run `./scripts/run-demo.ps1` for the deterministic golden flow. The script prepares the pinned official DataHub MCP runtime, verifies/seeds DataHub, builds as needed, and launches Cursivis.
5. Select `examples/broken-query.sql` and invoke Cursivis. Inspect the DataHub-grounded evidence before using any action.
6. To demonstrate durable organizational memory, choose **Save to DataHub**, review the confirmation, then confirm. Treat the write as successful only if the MCP read-after-write verification succeeds.

## Verification

The repository includes deterministic tests, secret scanning, browser-extension validation, a reproducible DataHub seed, judge-readable example artifacts, and a SHA-256 checksum for the versioned installer. The runtime intentionally fails closed for DataHub-grounded requests if the required MCP/DataHub context cannot be resolved.

Windows Defender SmartScreen may show **Unknown Publisher** because the installer is not code-signed. The installer is self-contained for 64-bit Windows. Pre-existing optional voice/realtime infrastructure is isolated from the hackathon DataOps path; the golden flow does **not** require an OpenAI API key.

See `README.md`, `HACKATHON_DISCLOSURE.md`, and `examples/` for architecture, setup, disclosure, and expected artifacts.
