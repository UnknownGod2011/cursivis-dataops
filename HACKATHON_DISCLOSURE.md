# Hackathon disclosure

Cursivis DataOps builds on selected pre-existing Cursivis interaction infrastructure owned by the entrant: Windows selected-text capture, the context orb and Result Panel, safe Insert/Replace/Copy actions, browser bridge, settings, and tests.

The DataHub-grounded Gemini provider, catalog-context architecture, deterministic demo materials, operational scripts, DataHub write-back workflow, documentation, and hackathon-specific testing were created for this submission. DataHub itself and its APIs remain separate open-source projects; this repository does not vendor DataHub.
