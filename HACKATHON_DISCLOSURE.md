# Hackathon disclosure

Cursivis DataOps builds on selected pre-existing Cursivis interaction infrastructure owned by the entrant: Windows selected-text capture, the context orb and Result Panel, safe Insert/Replace/Copy actions, browser bridge infrastructure, settings scaffolding, and associated tests.

The DataOps work was created for this submission: the Gemini reasoning provider, official DataHub MCP Server client and runtime read path, MCP-confirmed `save_document` write-back with read-after-write verification, DataHub catalog-context architecture, deterministic DataHub OSS demo catalog and seed tooling, operational scripts, DataOps-specific settings, documentation, and hackathon-specific tests.

DataHub OSS/Core, the official DataHub MCP Server, Gemini, and their APIs remain separate upstream projects; this repository does not vendor DataHub or the MCP server.
